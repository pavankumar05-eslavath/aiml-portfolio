# Runtime dependencies.

# torch is intentionally NOT pinned here, because the right wheel depends on the
# target accelerator and installing the default (CUDA) build pulls ~2.5 GB that a
# CPU deployment never uses. Install it first, then this file:
#
#   CPU only (what the Dockerfile and the README use):
#     pip install torch==2.8.0 torchvision==0.23.0 \
#       --index-url https://download.pytorch.org/whl/cpu
#   CUDA 12.x:
#     pip install torch==2.8.0 torchvision==0.23.0
#
#   pip install -r requirements.txt
#
# torchvision is required for the fast (torchvision-backed) image processors in
# transformers; without it, image preprocessing falls back to a slower path.
